Before connecting, one-time setup on GitHub:
  1. Create a new private repository just for data — e.g. ledger-data. It does not need Pages enabled; it's only used as storage.
  2. Go to github.com/settings/personal-access-tokens/new and create a fine-grained token scoped only to that one repository, with Contents: Read and write permission and nothing else.
  3. Paste the details below. They're saved only in this browser's local storage.
